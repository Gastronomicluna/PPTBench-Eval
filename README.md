# PPTBench Evaluation

## Overview

PPTBench is a benchmark for evaluating the performance of Large Language Models (LLMs) on various tasks. It includes a set of tasks that are designed to test the capabilities of LLMs in different domains, such as natural language understanding, reasoning, and problem-solving.

## How to Use

1. Ensure you have Python 3.11 installed.
2. We use Poetry for dependency management. Install it from [here](https://python-poetry.org/docs/#installation).
3. Install the dependencies:

   ```bash
   poetry install
   ```

   Note: If you encounter the issue that `poetry install` stuck at pending, refer to [this issue](https://github.com/python-poetry/poetry/issues/8623).
